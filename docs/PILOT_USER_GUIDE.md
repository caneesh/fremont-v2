## 1. Getting Started

### Logging In

1. Open PhysiScaffold in your browser
2. You'll see the **Pilot Access** login screen
3. Enter your access code (format: `PILOT-ALPHA-XXX`)
4. Click **"Access PhysiScaffold"**

### Welcome Screen

After logging in, you'll see a welcome screen showing:
- Your name
- Daily limits (problems, hints, prerequisites, reflections)
- Quick usage tips

Click **"Start Learning"** to enter the app.

### Navigation

- **Bottom navigation bar** (mobile): Access different sections
- **Logout button**: Top-left corner (mobile) or top-right (desktop)
- **Back buttons**: Navigate between sections

## 3. Learning a Pattern

Each pattern has three stages that build your mastery:

### Stage 1: Learn (Blue)

**Goal**: Understand the core concept and approach

1. Click the **"Learn"** button on a pattern
2. You'll be given 1-2 introductory problems
3. These problems are simpler (difficulty 1-2)
4. Focus on understanding the **why**, not just the **how**

**What you'll see:**
- Step-by-step problem breakdown
- Conceptual explanations
- Common traps to avoid

### Stage 2: Practice (Green)

**Goal**: Apply the pattern with guidance

1. After completing Learn, the **"Practice"** button activates
2. You'll solve 2 practice problems
3. These are moderate difficulty (2-3)
4. You can still use hints, but try to need fewer

**What you'll see:**
- Less hand-holding than Learn
- Focus on applying the pattern independently
- Feedback on your approach

### Stage 3: Drills (Purple)

**Goal**: Build speed and confidence

1. After completing Practice, **"Drills"** activates
2. You'll solve 5 drill problems
3. Mixed difficulty levels
4. Aim to solve with minimal hints

**What you'll see:**
- Timed practice feeling
- Variety of problem types
- Mastery score updates

## 4. Solving Problems

### Problem Screen Layout

When you enter a problem, you'll see:

1. **Problem Statement**: The physics question at the top
2. **Step List**: Expandable steps to solve the problem
3. **Current Step**: The step you're working on
4. **Input Area**: Where you enter your answer
5. **Hint Button**: Access progressive hints

### Working Through Steps

1. **Read the step goal** - Understand what this step asks
2. **Think before typing** - Form your approach mentally first
3. **Enter your answer** - Type in the input field
4. **Submit** - Click the submit button or press Enter
5. **Review feedback** - Learn from correct/incorrect responses

### Step Types

| Type | What to Do |
|------|------------|
| **Conceptual** | Identify the physics principle |
| **Setup** | Draw diagrams, define variables |
| **Equation** | Write the relevant equation |
| **Calculation** | Solve numerically |
| **Analysis** | Interpret results, check sanity |

## 5. Using Hints Effectively

PhysiScaffold provides **5 levels of progressive hints**. Use them strategically!

### Hint Levels

| Level | Name | What It Provides |
|-------|------|------------------|
| 1 | **Nudge** | A gentle push in the right direction |
| 2 | **Conceptual** | The physics principle to apply |
| 3 | **Strategic** | The approach to take |
| 4 | **Procedural** | Step-by-step guidance |
| 5 | **Reveal** | Complete solution (use sparingly!) |

### Best Practices

1. **Start with Level 1** - Often a small nudge is enough
2. **Wait before escalating** - Think for 30 seconds before the next level
3. **Avoid Level 5 unless stuck** - Revealing hurts your mastery score
4. **Learn from hints** - Don't just copy; understand why

### Impact on Mastery

- **No hints used**: Maximum mastery gain (+15%)
- **Hints 1-2 used**: Moderate gain (+8%)
- **Hints 3-4 used**: Small gain (+3%)
- **Reveal used**: Mastery penalty (-10%)

## 6. Practice and Drills

### Practice Mode

After completing the Learn stage:

1. Return to the track page
2. Click **"Practice"** on the pattern
3. Solve 2 practice problems
4. Badge updates to "✓ Practiced" when complete

**Tips for Practice:**
- Try to use fewer hints than in Learn
- Focus on recognizing the pattern quickly
- Time yourself informally

### Drill Mode

After completing Practice:

1. Click **"Drills"** on the pattern
2. Solve 5 drill problems
3. Counter shows attempts: "Drills (1)", "Drills (2)", etc.

**Tips for Drills:**
- Aim for speed AND accuracy
- Challenge yourself to go hint-free
- Repeat drills to build confidence

### Mastery Meter

Your mastery for each pattern is tracked:

| Mastery | Color | Meaning |
|---------|-------|---------|
| 0-40% | Red | Needs work |
| 40-75% | Yellow | Progressing |
| 75-100% | Green | Strong understanding |

## 7. Tracking Your Progress

### Pattern Progress Badges

On the track page, each pattern shows its status:

- **Blue "Learn"** - Not started or in progress
- **"✓ Learned"** - Learn stage complete
- **"✓ Practiced"** - Practice stage complete
- **"Drills (N)"** - Number of drill sessions completed

### Track Progress Bar

At the top of each track page:
- Progress bar shows overall completion
- "X of Y patterns mastered" count
- Percentage complete

### What Counts as "Mastered"

A pattern is mastered when:
1. Learn stage completed
2. Practice stage completed
3. Mastery score ≥ 75%

## 8. Error Recovery and Review

### Common Mistakes

PhysiScaffold tracks common error patterns:

| Error Type | Example |
|------------|---------|
| **Sign errors** | Wrong direction for velocity |
| **Sin/Cos swap** | Using sin instead of cos for incline |
| **Missing constraints** | Forgetting string is inextensible |
| **Unit errors** | Mixing m/s with km/h |

### Error Watchlist

Access via the **Errors** tab in Study Path:

1. See patterns where you've made mistakes
2. View specific error types
3. Get targeted practice problems
4. Track improvement over time

### Reviewing Mistakes

1. Go to Study Path → Errors tab
2. Click on an error pattern
3. Review the concept explanation
4. Practice with targeted problems

## 10. Tips for Success

### Before Starting a Problem

1. **Read carefully** - Understand what's being asked
2. **Identify the physics** - What principles apply?
3. **Sketch if needed** - Draw a diagram mentally or on paper
4. **Estimate the answer** - What order of magnitude?

### While Solving

1. **Work systematically** - Follow the step structure
2. **Check units** - Dimensional analysis catches errors
3. **Use hints strategically** - Don't jump to Reveal
4. **Learn from mistakes** - Wrong answers teach too

### After Completing

1. **Review the solution** - Even if you got it right
2. **Note the pattern** - How does this connect to others?
3. **Identify weak spots** - What tripped you up?
4. **Plan next steps** - What to practice tomorrow?

### Building Long-Term Mastery

1. **Consistency beats intensity** - 30 min daily > 3 hours weekly
2. **Complete full cycles** - Learn → Practice → Drill for each pattern
3. **Return to weak patterns** - Use the Error Watchlist
4. **Connect patterns** - See how they work together
